# Greenmole 1.6.1-greenmole.15

This release addresses the remaining AngularJS and npm tooling findings from
Greenmole.14. It preserves existing connection, video, keyboard and deployment
configuration behavior.

## AngularJS security backports

The official AngularJS 1.8.3 package has no supported security release. Greenmole
now carries a minimal core-only security backport based on that exact official
release, with the original Google MIT license, immutable source checksums and a
complete reviewable patch. This is maintained by Greenmole; it is not an official
Google or Apache AngularJS release.

The changes correct nine applicable advisories: resource URL policy bypass,
SVG image and srcset sanitization, excessive work in currency formatting,
regular expression copying, URL input validation and srcset parsing, and
Internet Explorer's restored-textarea interpolation issue. Every srcset
candidate is checked using browser-compatible token boundaries, including
data URLs and malformed nested descriptors. The optional `angular-resource`
and `angular-sanitize` modules are not shipped and are not represented as
patched. Existing routing remains on the unchanged `angular-route` 1.8.3.

See the [source and advisory mapping](../client/guacamole/src/main/frontend/vendor/angularjs/SECURITY-PATCHES.md)
for patch provenance, limitations and reproduction commands. The packaged
minified AngularJS is generated from the reviewed source during each build.
The original advisory list remains explicitly tracked because npm's registry
audit does not independently assess this local package.

## Dependency and build changes

- Update the affected common-JS test dependencies: body-parser, brace-expansion,
  engine.io, qs and socket.io-parser. Retain Greenmole.14's follow-redirects and
  markdown-it fixes.
- Update the affected frontend build dependencies and CSV parser, and move
  MessageFormat to `@messageformat/core` 3.4.1 with a tested adapter for existing
  translation syntax. Correct malformed ICU messages in three shipped locales.
- Replace the abandoned template-cache plugin with a small local webpack
  plugin using the maintained HTML minifier. Preserve template keys,
  whitespace handling and safe JavaScript serialization.
- Align common-JS's Node/npm toolchain with the frontend's pinned versions.
  Preserve pinned native dependencies and Docker base images.
- Generate complete dependency notices from reviewed local license metadata
  without modifying the original upstream license files or downloading licenses
  during builds.

## Validation

Security regressions execute against real browser APIs and the actual packaged
AngularJS asset. They include normal text/model behavior, URL validation,
SCE allowlists, SVG images, every srcset binding form and bounded hostile inputs.
A simulated IE document mode checks the textarea guard; this is not a claim of
testing in Internet Explorer itself. The original unpatched source fails these
regressions, while the corrected source passes.

Build and packaged-app validation also cover login/logout, routes, translations
and ICU pluralization, preferences, mobile defaults and keyboard settings. The
release validation record records final test results, image identities and
deployment configuration comparisons.

All original Apache license/notice files and upstream histories are preserved.
The added AngularJS source and attribution remain MIT licensed. This release
addresses the identified findings; it does not claim that any framework or
dependency tree is free of undiscovered vulnerabilities. Continuing to use
AngularJS requires maintaining these backports and reviewing new advisories.
