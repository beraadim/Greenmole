# Greenmole 1.6.1-greenmole.6

The native keyboard control bar now reserves space in the client layout. The
remote desktop uses the area above its measured height instead of including
space hidden behind the controls. This includes narrow screens where the bar
wraps. Opening the device software keyboard still preserves the desktop's
resolution and zoom; smart and manual panning remain available while typing.

New iOS browser preferences default to **Native keyboard** and **Touchpad** mouse
mode. Dragging moves the pointer rather than clicking the location under a finger.
Detection covers iPhone, iPod touch and desktop- or mobile-mode iPad. Saved input
and mouse preferences are honored independently. Older Greenmole versions saved
all defaults automatically, so existing stored choices are preserved rather than
guessing which were deliberate; users can change their default input preferences.
Native keyboard presentation still requires a deliberate **Show keyboard** tap.

Touchpad mode also takes precedence over advertised remote touch support, so a
server's touch capability cannot silently bypass the chosen relative mouse mode.
Absolute mouse mode continues to use direct touch when the server supports it.

[Build inputs](1.6.1-greenmole.6.json) retain the dependency commits and base image
digests from Greenmole.5. Apache licenses, attribution and upstream notices are
preserved. Server codecs and browser video transport are unchanged.

## Validation and deployment

Both pinned Linux/amd64 runtime images were built from immutable source
`4664381abfb0d3fc3512eeff57b15853f62a7030`. Validation passed:

- 116 frontend Node tests, including 11 additional preference, sizing and mouse
  regressions. Existing viewport and smart-pan tests now cover the reserved bar.
- 296 native tests, 64 Java unit tests and 256 Firefox browser tests. Three
  existing browser-capability skips and three existing webpack bundle-size
  warnings remain.
- Isolated packaged gateway checks: 16 effective locale versions, byte-identical
  mascot assets, browser video/fallback APIs, RDP plugin selection and
  web-to-guacd connectivity.
- Ten packaged browser preference cases: fresh iOS defaults, desktop defaults,
  saved input/mouse choices, partial preferences and persistence.
- Three actual packaged Angular client/CSS cases: remembered Native mode at
  768-pixel and wrapped 360-pixel widths, and switching from physical keyboard
  input to Native mode. Initial Native handshakes used the measured usable
  desktop, 768×974 or 360×646, with no duplicate toolbar padding.
- Packaged client checks also verify normal fitting, real height-only browser
  resize while the keyboard is closed, stable resolution and manual zoom through
  software-keyboard geometry changes, local Pan capture, desktop-bottom access,
  relative pointer input despite server touch support, explicit absolute touch
  and complete fixture cleanup. Screenshots passed visual review.
- Anonymous live desktop/mobile login checks passed with the correct version,
  responsive layout, mascot and icons, and no JavaScript errors. Screenshots
  passed visual review and the temporary forwarding was removed.
- Attribution verification: 92 modification notices, 213 unchanged upstream legal
  files and both reachable imported histories. Source scanning found no new
  secrets; existing scanner flags are unchanged upstream examples or identifiers.

Browser tests used desktop Chromium with emulated device navigator and visual
viewport geometry. They did not authenticate or establish an RDP connection.
Actual iPadOS Safari keyboard presentation and remote interaction still need
device testing. All owned test containers, networks and forwarding resources
were removed; production stayed unchanged during isolated checks.

Greenmole.6 is deployed on Oberon. Only the two gateway image references changed;
configuration, runtime settings and unrelated containers were preserved. The
running pair matches the tested images. Guacd is healthy, the web API responds,
and startup checks show zero restarts, no OOM termination and no critical errors.
The Greenmole.5 image pair remains tagged for rollback.

[The validation record](1.6.1-greenmole.6-validation.json) contains exact source
and image identities, asset hashes and sanitized checks. Images were not
published to a registry. Private configuration, credentials and raw runtime
logs are excluded. The common-JS source tree and packaged bundle match
Greenmole.5; this input/layout release did not repeat the unchanged four-case
video matrix recorded for [private.16](1.6.1-private.16-validation.json).
