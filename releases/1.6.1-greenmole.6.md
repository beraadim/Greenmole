# Greenmole 1.6.1-greenmole.6

The native keyboard control bar now reserves space in the client layout. The
remote desktop uses the area above its measured height instead of including
space hidden behind the controls. This includes narrow screens where the bar
wraps. Opening the device software keyboard still preserves the desktop's
resolution and zoom; smart and manual panning remain available while typing.

New iOS browser preferences default to **Native keyboard** and **Touchpad** mouse
mode. Dragging moves the pointer rather than clicking the location under a finger.
Detection covers iPhone, iPod touch and desktop- or mobile-mode iPad. Saved input
and mouse preferences are honored independently. Older Greenmole versions saved
all defaults automatically, so existing stored choices are preserved rather than
guessing which were deliberate; users can change their default input preferences.
Native keyboard presentation still requires a deliberate **Show keyboard** tap.

Touchpad mode also takes precedence over advertised remote touch support, so a
server's touch capability cannot silently bypass the chosen relative mouse mode.
Absolute mouse mode continues to use direct touch when the server supports it.

[Build inputs](1.6.1-greenmole.6.json) retain the dependency commits and base image
digests from Greenmole.5. Apache licenses, attribution and upstream notices are
preserved. Server codecs and browser video transport are unchanged.

Validation and deployment evidence will follow the immutable source build and
isolated packaged checks.
