# Greenmole 1.6.1-greenmole.9

Native keyboard mode now supports local pinch zoom and horizontal as well as
vertical panning. Enable **Pan desktop**, pinch to zoom around the point between
your fingers, then drag to bring another part of the desktop into view. Turning
Pan off retains that zoom and confines the pointer to the visible desktop.
Hiding the native keyboard continues to turn Pan off automatically.

An independent, one-time iOS preference migration enables Native keyboard for
browsers which retained the old automatically saved None default. This fixes
iPhone sessions where device detection succeeded but a legacy preference
overrode it. Existing Text input and On-screen keyboard choices are preserved,
and all later explicit choices, including None, survive reload. Desktop
preferences are unchanged.

Local navigation never sends a remote click, drag, scroll, resize or reconnect.
Gesture ownership is retained until every finger is lifted, including when Pan
changes during a gesture. Pinching preserves the desktop point under the fingers
when a centered display grows into a scrollable one, and switching between one
and two fingers does not jump. The relative pointer accumulator is rebased at
view edges so reversing direction responds immediately. Deferred input keeps
its original coordinates and order while local cursor feedback remains visible
after a zoom change. Closing the view removes the matching touchpad handlers.

See [Native device keyboard](../docs/native-keyboard.md) for usage and
[the pinned build inputs](1.6.1-greenmole.9.json) for reproducible component
versions. Server codecs, video transport and dependency pins are unchanged from
Greenmole.8. Apache licensing and upstream attribution are preserved.

## Validation

The pinned Linux/amd64 web image was built from source
`0360ea14e25d80c2f6a04e08d4a37f3c2eac1739` and is ready for deployment:

- All 159 frontend Node tests pass, including 30 new regressions. Production
  webpack passes with three existing bundle-size warnings.
- The container build passes all 64 Java unit tests and 256 Firefox browser
  tests, with three existing browser-capability skips.
- Compiled-UI WebKit 26 and Chrome 155 checks pass at both 768×1024 and
  390×844. At iPhone width, the keyboard strip wraps into two rows with visible
  44×44 controls and a full-width editor.
- The exact packaged web image passes the same gesture checks in both browsers
  at 390×844. Its revision/version/architecture, all 16 effective locale
  versions and unchanged mascot and common-JS assets are verified.
- Attribution verification and the staged secret scan pass. The running
  Greenmole.8 containers remain unchanged; owned temporary containers, networks,
  synthetic configuration and forwarding were removed after isolated testing.

The browser checks use an emulated iPhone navigator, synthetic touch/viewport
events and a local display transport; they do not authenticate or open an RDP
connection. Actual iPhone Safari keyboard and finger gestures still require
device testing. The native server and common-JS video sources are unchanged;
the native server was not rebuilt and its tests were not repeated.

The [validation record](1.6.1-greenmole.9-validation.json) records the completed
checks, immutable web image identity and runtime build status. The image is
available locally on Oberon and was not published to a registry. Production
deployment is a separate action and has not been performed.
