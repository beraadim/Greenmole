# 1.6.1-private.2

Built and deployed on Oberon on 2026-10-15, replacing `1.6.1-private.1` in the
existing `windows11-guac-lab` Compose project. This remains an internal build
of Apache's unreleased 1.6.1 staging baseline.

## Changes

- Image decoding failures release the browser drawing queue. Decoders, decoded
  frames, bitmaps and blob URLs are released on success, failure, cancellation
  and late completion. Correct BYOB stream offsets, remainder types, EOF and
  cancellation handling support streamed decoding.
- Image contents are classified once per update, preserving existing codec
  choices, compression quality and lossless behavior.
- Completed frames skip the heuristic 10 ms batching delay. Explicit frame
  boundaries interrupt batching while client backpressure remains bounded and
  enforced. Shutdown interrupts waits; cursor state is read under its lock.
- Thumbnails are composed directly at their small output resolution, preserving
  layer transformations, clipping, stacking and grouped opacity.
- An optional overlay shows rendered/desktop FPS, browser processing delay,
  decoded protocol download throughput and the committed WebSocket/HTTP
  transport. Enable **Display → Show performance statistics** in the Guacamole
  menu. Collection stops when disabled or the view is destroyed. No instruction
  contents are retained or logged. Processing delay is not network RTT or
  input latency; protocol throughput excludes transport headers, TLS and
  transport compression. Missing/stale measurements display a dash.

Refresh the browser and reconnect after deployment to load the new client.
Browser assets have new content hashes/build identifiers.

## Validation

- Native CUnit suites: 132 passed, including nine new codec/scheduler tests.
- Java tests: 56 passed, no failures, errors or skips.
- Browser suites: all 57 passed in Chrome 155 and Firefox 158. The 42 new tests
  cover decoded resources, rejection/cancellation, real decoder integration,
  BYOB delivery, thumbnails, diagnostics and transport fallback.
- Real AngularJS directive fixture: six rendering/lifecycle checks passed;
  overlay screenshot visually inspected.
- Isolated preflight with the existing mounted configuration passed HTTP
  startup, numeric UID/GID checks, configuration readability, web-to-guacd
  connectivity and RDP plugin handshake. No ports were published by preflight.
- After cutover: web root, language API and new JavaScript/translation assets
  served successfully; guacd healthy; both containers running without restarts.

Focused benchmarks, not end-to-end session speed measurements:

- Chrome software-rendered 3840×2160 desktop with 13 layers, 320×180 thumbnail,
  30 iterations: median thumbnail work 7.4 → 0.5 ms, p95 7.9 → 0.6 ms. The
  primary temporary canvas decreases from 31.6 MiB to 225 KiB; opacity groups
  also use thumbnail-sized canvases.
- Optimized native build, 20,000 selections of a 256×256 PNG-friendly tile:
  content classification 0.246 → 0.136 seconds, preserving the PNG choice.
- Deterministic scheduler tests verify zero heuristic delay for already-ready
  frames, boundary arrival during batching, unchanged unmarked batching,
  retained/capped client lag waits, frame accounting and shutdown interruption.

Real desktop workloads over LAN/WAN remain user acceptance testing; no overall
FPS or input-latency speedup is claimed from these isolated benchmarks.
