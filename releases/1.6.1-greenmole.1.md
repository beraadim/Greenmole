# Greenmole 1.6.1-greenmole.1

First public Greenmole source release, carrying the reviewed downstream work
through 1.6.1-private.16. Greenmole is an independently maintained fork of
Apache Guacamole, not an Apache Software Foundation release. Its baseline is
the unreleased Apache staging/1.6.1 source recorded in UPSTREAM.json.

The visible application name, login mark, favicons and translated product text
now identify Greenmole. The source repository and new local image tags use the
Greenmole name. Technical Guacamole protocol, package, extension and configuration
identifiers remain compatible with existing deployments.

Apache licenses, NOTICE text, source attribution and bundled third-party notices
are retained. Changed upstream files carry prominent modification notices; the
repeatable attribution checker and DOWNSTREAM-CHANGES.json describe them. Both
imported upstream histories remain reachable.

Before public visibility, the release files and complete reachable Git history
are scanned for secrets, including commit/tag messages and historical blobs.
Only reviewed source refs are published; ignored runtime data and local audit
reports are excluded. Publication and validation evidence is recorded after
the completed checks. This source-publication task does not deploy changes to
a running gateway or Mac application.

## Build and validation

The first public source revision is
`1f34dac5917e1369fc0668869d716c7e85c7ad4d`. Both pinned Linux/amd64 images
were built from an immutable archive of that commit, with Maven tests explicitly
enabled. Dependency and base-image pins are unchanged from private.16.

Validation passed:

- 286 native tests and 64 Java unit tests.
- 259 Chrome browser tests, with no skipped tests.
- 256 Firefox browser tests, with three existing browser-capability skips.
- 40 frontend tests, the production frontend build, and a browser smoke check of
  the built login screen, version display, original logo and favicon reset.
- An isolated test of the packaged images, using synthetic configuration on a
  temporary internal network: all 16 translations loaded, Greenmole names and
  version were served, SVG/PNG assets matched the source bytes, the browser video
  and fallback APIs were present, and the RDP plugin and web-to-guacd connection
  responded correctly.
- The attribution checker: 83 modified upstream files carry file-local notices;
  all 213 upstream license and notice files are unchanged; both imported Apache
  histories remain reachable.

The temporary test containers and network were removed. The running gateway's
container identities, image identities, restart counters and startup timestamps
were unchanged. These images were built locally for validation; they were not
published to a container registry or deployed to a live service.

The video protocol and performance changes remain those validated in
[private.16](1.6.1-private.16-validation.json). This naming and attribution
release did not repeat the four video playback/fallback integration cases.
[The validation record](1.6.1-greenmole.1-validation.json) contains source and
image identities, test counts, asset hashes and the isolated runtime results.

## Publication review

[The publication audit](1.6.1-greenmole.1-publication-audit.json) records the
reviewed source, full historical scans and classified example/constant matches.
No actual credentials or private key material were detected. Ignored runtime
material, local reports, unreachable Git objects and reflogs are not published.
The audit is a risk-reduction check, not a guarantee that no possible secret
can exist. The documentation-only evidence commit and new tag are scanned
separately before the initial source push.
