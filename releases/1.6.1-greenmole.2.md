# Greenmole 1.6.1-greenmole.2

Greenmole's new logo is a cute green mole with a pink nose and digging paws.
The login screen uses a 96-pixel logo, with transparent PNG derivatives for
browser icons, touch icons and the README. The original transparent artwork,
asset paths and generation prompt are documented in [branding notes](../docs/branding.md).
The old letter-based SVG mark is removed.

This release carries the protocol, video decoding, image fallback, connection
recovery and performance behavior already validated through
[private.16](1.6.1-private.16-validation.json). Configuration keys, extension
identifiers and supported connection settings remain compatible. The visible
application version advances to `1.6.1-greenmole.2`.

[Build inputs](1.6.1-greenmole.2.json) retain the dependency commits and base
image digests from Greenmole.1; only the release version and distinct downstream
image tags change. Apache licenses, attribution and upstream NOTICE files are
preserved.

## Validation and deployment

The requested pinned Linux/amd64 image builds, release validation and deployment
to Oberon are pending. Deployment must preserve the current gateway configuration
and retain the previous image pair for rollback. Completed validation and
deployment results will be recorded after those checks.
