# Greenmole 1.6.1-greenmole.10

The native keyboard control bar now provides a **Settings** button, shown as a
gear on narrow screens, which opens the current connection's settings panel.
Opening settings dismisses the device keyboard and turns Pan desktop off.
Repeated taps keep the panel open; closing it leaves the keyboard hidden until
the user chooses **Show keyboard**. The action does not send remote input.

Controls retain a minimum 44-pixel touch target. Narrow-screen button margins
allow the additional action without adding a third row at common phone widths.
The existing toolbar measurement accounts for wrapping and desktop space.

See [Native device keyboard](../docs/native-keyboard.md) for usage and
[the pinned build inputs](1.6.1-greenmole.10.json) for component versions.
Dependency pins, native server code and common-JS video transport are unchanged
from Greenmole.9. Apache licensing and upstream attribution are preserved.
