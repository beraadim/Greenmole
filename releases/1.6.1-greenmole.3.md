# Greenmole 1.6.1-greenmole.3

This release corrects two initial viewport sizing races. The browser could use
an outdated viewport measurement for its connection handshake after the page
layout changed. It now remeasures the current viewport at the waiting and connected transitions
before enabling queued size updates. On the
RDP side, deferred display negotiation could let an older resize overwrite a
newer requested viewport; the pending resize now retains the latest request and waits for server Display
Control capabilities before sending it. Unsent requests do not consume the
resize throttle, while failed sends remain eligible for rate-limited retry.
Together these changes keep initial desktop sizing aligned with the current
browser viewport while preserving subsequent resizing.

The cute green mole login logo and browser icons are retained. Protocol names,
authentication and extension configuration, video decoding choices and image
fallback settings remain compatible. The visible application version advances
to `1.6.1-greenmole.3`.

[Build inputs](1.6.1-greenmole.3.json) retain every dependency commit and base
image digest from Greenmole.2. The release version and distinct downstream image
tags advance together. Apache licenses, attribution and upstream NOTICE files
are preserved.

## Validation and deployment

Focused resize regression tests, pinned Linux/amd64 image builds and isolated
runtime validation are pending. Completed results will be recorded after those
checks. This release preparation does not change the running gateway; live
deployment requires authorization and must preserve its existing configuration
and retain the previous image pair for rollback.
