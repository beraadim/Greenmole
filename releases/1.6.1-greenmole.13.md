# Greenmole 1.6.1-greenmole.13

Keyboard layouts and shortcut preferences now have separate responsibilities.
The browser offers Auto, Windows-friendly, Native Mac and Keep Control shortcuts.
Auto suggests Mac semantics on Apple devices and retains the Windows-friendly
policy elsewhere. The preference takes effect on reconnect and requires
Greenmole RDP 0.1.32 for host interpretation. Existing host configuration and
ordinary Windows RDP key events remain intact.

An allowlisted browser preference travels through an optional guacd argument
into exact, versioned OEM keyboard subtype values. Administrator and host
settings take priority; older daemons/hosts ignore the optional preference.
No connection name or video negotiation changes are involved.

The historical Norwegian Bokmål layout spelling now resolves to the existing
Norwegian keymap. Unknown layout names produce a warning before the existing US
fallback. The browser language is never used to guess a keyboard layout.

See [keyboard layouts](../docs/keyboard-layouts.md) for compatibility and tests.
This release uses the existing pinned dependencies and rebuilds both images.
The local frontend suite passed all 183 tests and the production build. Native,
Java and packaged-runtime validation are recorded separately after image builds.
Physical client acceptance remains necessary for host/application combinations.
