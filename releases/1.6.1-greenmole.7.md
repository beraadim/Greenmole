# Greenmole 1.6.1-greenmole.7

All input modes now size the desktop from the visible browser viewport. In
Greenmole.6, None mode used the larger layout window instead, which could put
the macOS Dock below Safari's visible area. Native mode continues to reserve
only the measured permanent keyboard control strip. Opening the software
keyboard preserves the remote resolution and zoom for local panning.

Existing iOS browser profiles now receive the Touchpad default once. Earlier
versions automatically saved Touchscreen as a default, and Greenmole.6 preserved
that old value. After this initialization, explicit Touchscreen or Touchpad
choices from the connection menu are saved immediately and survive reload.
Keyboard settings, unrelated preferences and non-iOS defaults remain unchanged.

[Build inputs](1.6.1-greenmole.7.json) retain the dependency commits and base image
digests from Greenmole.6. Apache licenses, attribution and upstream notices are
preserved. Server codecs and browser video transport are unchanged.

## Validation and deployment

Both pinned Linux/amd64 runtime images were built from immutable source
`beecec2cb25d268f7dca7c8d89038654cd69e39c`. Validation passed:

- 122 frontend Node tests, including six net additional preference/controller
  and viewport regressions.
- 296 native tests, 64 Java unit tests and 256 Firefox browser tests. Three
  existing browser-capability skips and three existing webpack bundle-size
  warnings remain.
- Isolated packaged gateway checks: 16 effective locale versions, byte-identical
  mascot assets, browser video/fallback APIs, RDP plugin selection and
  web-to-guacd connectivity.
- A direct regression comparison against the exact packaged Greenmole.6 image
  in WebKit using the full production client template and tiled DOM. With
  layout height 1024 and visible height 944, None mode clipped 80 pixels from
  the desktop bottom; with pageTop 44, it clipped 36 pixels.
- Five full-client cases in each of Chromium and WebKit using the actual page
  controller, production client template, tiled directives and keyboard bar.
  None mode now requests 768×944 in that geometry and exposes the bottom.
  Native mode requests 768×894, reserving its control bar once. The Native →
  None transition restores the full visible height without subtracting keyboard
  occlusion from the remote resolution.
- Real menu radios, runtime input mode and stored preference agree. A legacy
  iOS absolute default migrates to Touchpad once, and later explicit Touchscreen
  and Touchpad choices both survive page reloads. Trusted Show/Hide gestures
  and software-keyboard geometry preserve remote size and manual 1.25 zoom.
  All cases have zero JavaScript errors; screenshots passed visual review.
- Anonymous live desktop/mobile login checks passed with the correct version,
  responsive layout, mascot and icons, and no JavaScript errors. Screenshots
  passed visual review and temporary forwarding was removed.
- Attribution verification: 92 modification notices, 213 unchanged upstream legal
  files and both reachable imported histories. Source scanning found no new
  secrets; existing scanner flags remain unchanged upstream examples or identifiers.

Browser tests used headless engines with emulated iPad navigator and viewport
geometry and a synthetic display/transport. They did not authenticate or open
an RDP connection. Actual iPadOS browser chrome and software-keyboard behavior
still require device testing. All owned test containers, networks and forwarding
resources were removed; production stayed unchanged during isolated checks.

Greenmole.7 is deployed on Oberon. Only the two gateway image references changed;
configuration, runtime settings and unrelated containers were preserved. The
running pair matches the tested images. Guacd is healthy, the web API responds,
and startup checks show zero restarts, no OOM termination and no critical errors.
The Greenmole.6 image pair remains tagged for rollback.

[The validation record](1.6.1-greenmole.7-validation.json) contains exact source
and image identities, asset hashes and sanitized checks. Images were not
published to a registry. Private configuration, credentials and raw runtime
logs are excluded. The common-JS source tree and packaged bundle match
Greenmole.6; this input/layout release did not repeat the unchanged four-case
video matrix recorded for [private.16](1.6.1-private.16-validation.json).
