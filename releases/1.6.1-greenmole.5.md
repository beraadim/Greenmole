# Greenmole 1.6.1-greenmole.5

Native keyboard mode now keeps the remote desktop's resolution and local zoom
when the keyboard opens. Its control bar overlays the view instead of reducing
the initial desktop size. The remaining visible area scrolls over the full
desktop, including its bottom edge above a wrapped keyboard control bar.

**Show keyboard** enables **Pan desktop** and scrolls just enough to reveal the
last remote click, or a known pointer position if no click is available. This
is a local input hint; Greenmole does not receive remote text-caret or focused
field bounds. Manual panning takes control for the rest of that keyboard
opening. Later animation, pointer movement and keystrokes do not recenter it.
Turn Pan desktop off to use remote touch controls while typing. **Hide keyboard**
also turns panning off. Physical mouse and hardware keyboard input remain usable.

Pan gestures are captured before remote mouse/touch emulation. Gesture ownership
remains with its original local or remote target until all contacts end, even
if the user changes Pan mode during a gesture. Real rotation, multitasking width
changes and tiled connection layout changes can still resize the remote view.
Pinch zoom, composition input and manual keyboard dismissal remain under user
control. Viewport and toolbar tracking use event-driven listeners with teardown.

[Build inputs](1.6.1-greenmole.5.json) retain the dependency commits and base image
digests from Greenmole.4. Apache licenses, attribution and upstream notices are
preserved. Authentication, video encoding/decoding and image fallback are unchanged.

## Validation and deployment

Both pinned Linux/amd64 runtime images were built from immutable source
`9a3eb619d34e1e28d66d03ecbf6f6de430ae5bc9`. Validation passed:

- 105 frontend Node tests, including 37 additional regressions for keyboard
  controls, stable layout, gesture ownership and smart panning.
- 296 native tests, 64 Java unit tests and 256 Firefox browser tests. Three
  existing browser-capability skips and three existing webpack bundle-size
  warnings remain.
- Isolated packaged gateway checks: 16 effective locale versions, byte-identical
  mascot assets, browser video/fallback APIs, RDP plugin selection and
  web-to-guacd connectivity.
- Actual packaged Angular client and CSS checks with an in-page synthetic
  transport: unchanged remote geometry and manual zoom through native mode,
  keyboard show/hide and occlusion; last-click reveal; manual-pan precedence;
  explicit Show rearming; local-only Pan gestures and restored remote touch.
- Actual DOM scrolling exposes the desktop bottom above measured and 96-pixel
  toolbars. At 360 pixels wide the toolbar wraps, the editor occupies the full
  width and all seven buttons retain at least 44-pixel targets.
- Packaged native input regressions cover trusted-gesture focus, Unicode,
  composition, shortcuts, manual dismissal, pinch, rotation and teardown.
- Anonymous live desktop/mobile login checks passed with the correct version,
  responsive layout, mascot and icons, and no JavaScript errors. Screenshots
  passed visual review.
- Attribution verification: 92 modification notices, 213 unchanged upstream legal
  files and both reachable imported histories. Source scanning found no new
  secrets; existing scanner flags are unchanged upstream examples or identifiers.

Browser checks used desktop Chromium with emulated iPad navigator and visual
viewport geometry. They did not authenticate or establish an RDP connection;
actual iPadOS Safari software-keyboard appearance and remote interaction still
need device testing. All owned test containers, networks and SSH forwarding
resources were removed. Production stayed unchanged during isolated checks.

Greenmole.5 is deployed on Oberon. Only the two gateway image references changed;
configuration, runtime settings and unrelated containers were preserved. The
tested images match the running pair. Guacd is healthy, the web API responds,
and startup checks show zero restarts, no OOM termination and no critical errors.
The Greenmole.4 image pair remains tagged for rollback.

[The validation record](1.6.1-greenmole.5-validation.json) contains exact source
and image identities, asset hashes and sanitized checks. Images were not
published to a registry. Private configuration, credentials and raw runtime
logs are excluded. The common-JS source tree and packaged bundle match
Greenmole.4; this input/layout release did not repeat the unchanged four-case
video matrix recorded for [private.16](1.6.1-private.16-validation.json).
