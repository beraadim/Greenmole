# Greenmole 1.6.1-greenmole.5

Native keyboard mode now keeps the remote desktop's resolution and local zoom
when the keyboard opens. Its control bar overlays the view instead of reducing
the initial desktop size. The remaining visible area scrolls over the full
desktop, including its bottom edge above a wrapped keyboard control bar.

**Show keyboard** enables **Pan desktop** and scrolls just enough to reveal the
last remote click, or a known pointer position if no click is available. This
is a local input hint; Greenmole does not receive remote text-caret or focused
field bounds. Manual panning takes control for the rest of that keyboard
opening. Later animation, pointer movement and keystrokes do not recenter it.
Turn Pan desktop off to use remote touch controls while typing. **Hide keyboard**
also turns panning off. Physical mouse and hardware keyboard input remain usable.

Pan gestures are captured before remote mouse/touch emulation. Gesture ownership
remains with its original local or remote target until all contacts end, even
if the user changes Pan mode during a gesture. Real rotation, multitasking width
changes and tiled connection layout changes can still resize the remote view.
Pinch zoom, composition input and manual keyboard dismissal remain under user
control. Viewport and toolbar tracking use event-driven listeners with teardown.

[Build inputs](1.6.1-greenmole.5.json) retain the dependency commits and base image
digests from Greenmole.4. Apache licenses, attribution and upstream notices are
preserved. Authentication, video encoding/decoding and image fallback are unchanged.

Validation and deployment evidence will be recorded after the immutable source
build and isolated packaged checks have completed.
