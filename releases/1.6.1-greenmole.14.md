# Greenmole 1.6.1-greenmole.14

This release fixes the five open GitHub Dependabot alerts numbered 2–6 by
updating two transitive dependencies in the common-JS build-tool lockfile.

| Package | Previous | Fixed | Advisories |
| --- | --- | --- | --- |
| `follow-redirects` | 1.16.0 | 1.16.1 | [GHSA-q3jh-wrc6-jgq8](https://github.com/follow-redirects/follow-redirects/security/advisories/GHSA-q3jh-wrc6-jgq8), [GHSA-8r9p-f939-6h3c](https://github.com/follow-redirects/follow-redirects/security/advisories/GHSA-8r9p-f939-6h3c) |
| `markdown-it` | 14.3.0 | 14.3.3 | [GHSA-gfr2-rv44-r23c](https://github.com/markdown-it/markdown-it/security/advisories/GHSA-gfr2-rv44-r23c), [GHSA-r7fv-28h4-cvq7](https://github.com/markdown-it/markdown-it/security/advisories/GHSA-r7fv-28h4-cvq7), [GHSA-vfgh-jcmw-g37q](https://github.com/markdown-it/markdown-it/security/advisories/GHSA-vfgh-jcmw-g37q) |

The redirect fixes protect credential-header removal across origins. The
Markdown fixes address excessive parsing/rendering work on crafted input.
Only the version, resolved registry URL and integrity hash for these two
packages change; package manifests and other locked dependencies are preserved.
Their MIT licenses and all existing Apache attribution remain intact.

`follow-redirects` is reached through Karma's HTTP proxy dependency, while
`markdown-it` is used by JSDoc. Maven installs them with `npm ci` for testing and
documentation generation. They are not imported by Greenmole's remote desktop
frontend, and the Docker runtime receives packaged Java/browser artifacts rather
than the build-stage Node dependencies. The separate frontend lockfile contains
neither package. This scope finding is not a claim that all other dependencies
are free of vulnerabilities.

Local validation passed a clean `npm ci`, all 286 common-JS Chromium tests
(including WebCodecs), and JSDoc generation. The targeted packages no longer
appear in the npm audit results. Image-build, packaged-runtime and deployment
verification will be recorded after completion. No keyboard mapping, display,
video, authentication or session-lifecycle behavior is changed by this patch.
The release recipe retains the existing pinned base images and native sources.

## Separate audit findings

The broader npm audit reports five other affected common-JS build/test packages
and 20 affected packages in the frontend dependency tree. These counts describe
packages, not unique advisories, and predate this focused patch. Build-tool
findings require their own compatible updates; some suggested npm fixes entail
major upgrades or downgrades. Legacy AngularJS has no official patched version
for its reported findings and requires a separate maintained-fork or migration
assessment. These findings are not dismissed or represented as fixed by this
release. Actual impact depends on deployed code paths and input handling.
