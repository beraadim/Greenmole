# Reporting security vulnerabilities

Please report suspected Greenmole vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/beraadim/Greenmole/security/advisories/new).
The repository maintainer reviews reports. Do not publish exploit details,
credentials, private desktop contents or sensitive logs in a public issue.

Include the affected Greenmole revision or release, a minimal reproduction and
the expected security impact. Use synthetic accounts and sanitized diagnostics
where possible. No response or remediation deadline is guaranteed.

Greenmole is independently maintained and is not an Apache Software Foundation
release. If a problem also affects unmodified Apache Guacamole, follow the
[upstream security reporting guidance](https://guacamole.apache.org/security/)
as well. The two projects coordinate their own releases independently.
